# Device Hardware Inspection

Document ID: RB-HW-002
Keywords: hardware, power, enclosure, cable, inspection, sensor

## 4.1 — Physical inspection threshold

Request a physical device inspection only when power, enclosure, cable, or sensor evidence indicates a probable hardware fault. Network timeouts alone are not sufficient evidence.

## 4.2 — Safe inspection

Isolate power before opening an enclosure. Record visible damage and connector state without changing device configuration.
