# Driver Application Recovery

Document ID: RB-APP-003
Keywords: driver, application, session, background, offline, timeout, reporting

## 3.4 — Safe operator response

Confirm connectivity and application session state before requesting a restart or device inspection. Ask the driver to reopen the application and verify that the active session is still valid.

## 3.5 — Recovery confirmation

After the application reconnects, wait for a fresh heartbeat and status update. Do not mark the incident resolved until reporting remains stable through the normal service window.
